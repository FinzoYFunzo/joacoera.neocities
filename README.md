Este simple código en HTML y CSS representa un pequeño proyecto que comenzó en febrero de 2023 como una muestra de afecto y pasión por las [Geocities](https://en.wikipedia.org/wiki/GeoCities) y surfear el internet antiguo.

El desarrollo de este sitio consiguió efectos inusuales: una sensación de nostalgia de una época que ni siquiera he vivido. Sueño hasta el día de hoy haber conocido ese momento y haber estado conectado a la extraña _wired_ de esa época.

## dev
Recomiendo utilizar `live-server` para desarrollar sitios estáticos.

```sh
npm install -g live-server
live-server
```
